# myhoyts

Find a HOYTS cinema session today where nobody has booked a seat yet.

**Live:** https://myhoyts.xyz

Type your state and a HOYTS cinema, and the site lists today's sessions where seat bookings are still zero. Click a time to jump straight into the Hoyts booking.

## Stack

  - Node.js (zero dependencies, using Hoyts's public JSON APIs directly)
  - nginx + Let's Encrypt on a Hetzner VPS
  - HTML/CSS/JS frontend
